# Phase 1 wiring (Uno + TMC2209 + TCA9548A + AS5600)

Pin numbers here must match [include/pins.h](../../include/pins.h). Change one,
change both.

## Arduino Uno

| Uno pin | Goes to | Notes |
| ------- | ------- | ----- |
| D2 | TMC2209 STEP | |
| D3 | TMC2209 DIR | |
| D4 | TMC2209 EN | active LOW on most StepStick-style boards |
| A4 | TCA9548A SDA | fixed hardware I2C, not remappable |
| A5 | TCA9548A SCL | fixed hardware I2C, not remappable |
| 5V | TCA9548A VCC | |
| GND | TCA9548A GND, TMC2209 GND | common ground is mandatory |

## TCA9548A -> encoders

All AS5600s share address 0x36, which is why the mux exists. One channel per
joint:

| Channel | Joint | Status |
| ------- | ----- | ------ |
| SD0/SC0 | J1 | Phase 1 |
| SD1/SC1 | J2 | Phase 3 |
| SD2/SC2 | J3 | later |
| SD3/SC3 | J4 | later |
| SD4/SC4 | J5 | later |
| SD5/SC5 | J6 | later |

Each AS5600 also needs VCC and GND, taken from the Uno's 5V/GND rail (the mux
channel headers carry data only).

Mux address is 0x70 with A0/A1/A2 unjumpered. If you jumper them, update
`TCA9548A_ADDR`.

## Motor power

- Bench PSU +12 V -> TMC2209 VMOT
- Bench PSU GND -> TMC2209 GND (and tied to Uno GND)
- **100-470 uF electrolytic across VMOT/GND at the driver**, correct polarity
- Bench PSU current limit ~1 A during bring-up

## Stepper motor

Find the coil pairs with a multimeter: the two wires with continuity between
them are one coil. Pair 1 -> A1/A2, pair 2 -> B1/B2.

## Encoder mechanical

- Diametrically magnetized magnet (axial will not work)
- Magnet centered on the axis of rotation, 0.5-3 mm from the AS5600 die
- Mounted on the joint **output** shaft, after any reduction, so the reading is
  a true absolute joint angle
- No ferrous material near the magnet

## Safety

- Power off before rewiring
- **Never disconnect motor leads while VMOT is live**
- Start with conservative TMC2209 current (see [tmc2209-setup.md](../../docs/tmc2209-setup.md))
- Keep encoder wiring physically separated from motor phase wiring
