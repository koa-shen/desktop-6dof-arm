# Uno + TMC2209 + AS5600 + backlash switch

Single motor/encoder for now — AS5600 goes directly on the Uno's I2C bus, no
mux. Re-add the TCA9548A (see git history of this file) when testing
multiple steppers.

## Arduino Uno pins
- D2 -> TMC2209 STEP
- D3 -> TMC2209 DIR
- D4 -> TMC2209 EN (often active LOW)
- A4 -> AS5600 SDA
- A5 -> AS5600 SCL
- 5V -> AS5600 VCC
- GND -> AS5600 GND

## Contact switch (current backlash test)
- Contact switch: Omron V-156-1C25 (short-lever snap-action, SPDT), mounted
  so the lever is depressed while the arm is in contact with the load cell
  and releases the instant it separates.
  - COM -> GND
  - NO -> D7 (uses internal pullup, `INPUT_PULLUP`): LOW = touching, HIGH = separated
  - NC left unconnected
- The current switch-only firmware does not use the HX711 pins. D5/D6 remain
  available for the later load-cell-assisted test:
  - D5 -> HX711 DT (DOUT)
  - D6 -> HX711 SCK
  - HX711 VCC -> 5V, GND -> GND
  - Load cell -> HX711 E+/E-/A+/A- per module silkscreen
- Note: this switch has pretravel/hysteresis (press and release points
  differ) and bounces briefly on release, unlike a simple continuity loop.
  Firmware debounces the release with consecutive-sample confirmation, but
  the pretravel still adds a small, roughly constant offset to the measured
  backlash — fine for troubleshooting/comparison, worth keeping in mind if
  you need an absolute number later.

## Motor power
- Bench PSU +V -> TMC2209 VMOT
- Bench PSU GND -> TMC2209 GND
- Add 100-470uF electrolytic capacitor across VMOT/GND near driver
- Common ground between Uno and TMC2209 logic/motor grounds

## BIGTREETECH TMC2209 V1.3 VREF adjustment
- Do this with only the bench PSU connected: PSU + -> VS and PSU - -> GND.
  Disconnect the Arduino, motor, and other peripherals first.
- Multimeter black probe -> TMC2209 GND.
- Multimeter red probe -> the unlabeled upward-facing VS/VREF test pin nearest
  the EN pin.
- Confirm the voltage changes with the trim potentiometer before reconnecting
  the rest of the system. Do not infer driver current from the PSU current
  display.

## Stepper motor
- Identify two coil pairs with a multimeter and connect to A+/A- and B+/B-

## Safety
- Power off before rewiring
- Do not hot-plug motor leads
- Start with conservative current settings on TMC2209
